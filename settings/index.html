Session & Security
Sesi autentikasi aktif disimpan secara lokal di browser melalui enkripsi token PIN. Tombol logout akan menghapus credential lokal dan mengembalikan Anda ke gerbang login.
Ganti Password / PIN Akses
Ubah password PIN rahasia untuk autentikasi Hermes Control Center. Perubahan akan disimpan secara permanen di server lokal.
